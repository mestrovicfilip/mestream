# Changelog

## 0.2.0

The first public release.

- Guided first run: sign in with a code or QR code, choose a console if the
  account has several, and plain instructions when no console is set up.
- Settings menu with four tabs (Picture, Stream, Device, Console) and a short
  explanation under every setting.
- Everything on screen works by touch, controller, keyboard and mouse.
- 720p or 1080p at 60 fps, hardware-decoded, with Mestream's own scaling and
  sharpening.
- Sound that keeps only the reserve the network needs (typically about 20 ms),
  and carries on by itself when the output device changes.
- Reconnects on its own after the stream drops or the device wakes from sleep.
- Failure screen with *Try again*, *Copy error* and, when it would help,
  *Restart console*.

Tested on the ASUS ROG Xbox Ally X with an Xbox Series S.
